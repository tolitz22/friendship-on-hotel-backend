# Friendship On Hotel PMS — Backend

Laravel API foundation, paired with [frontend](https://github.com/tolitz22/friendship-on-hotel-frontend).

## Current scope
Initial API route, hotel/room-type/room schema, and documentation. **Not yet a complete bootstrapped Laravel app**: complete the Laravel application skeleton using Composer before attempting to run migrations or tests. No reservations, payments, or real inventory transactions have been implemented.

## Roadmap
1. Bootstrap Laravel with compatible PHP/Composer versions.
2. Resolve the business questions in `docs/BUSINESS_RULES.md`.
3. Introduce authentication, authorizations, booking inventory and concurrency tests.
4. Implement reservation lifecycle, billing and housekeeping separately.

Keep production credentials out of Git.
