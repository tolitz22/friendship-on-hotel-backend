# LOG-8.4B — Subscription plan catalog

Run php artisan migrate --force before using the new Subscriptions module. Dedicated platform operators may create, list, edit, activate and deactivate plans and view paginated revision history. Catalog prices are PHP integer centavos, monthly and annual entered independently; zero is permitted for a free package. Limits are positive integers or explicit null (unlimited). New plans can be inactive and no packages or prices are seeded. Code is unique and immutable. Updates require the current revision, lock the plan row and atomically append a snapshot with actor ID and timestamp on actual changes. No hard deletion endpoint. Audit grows only on plan changes, not monitoring requests. Plan activation means catalog availability only. No hotel assignments, invoice generation, payment collection, VAT handling, trial clocks, limit enforcement or access suspension. Future subscriptions must snapshot agreed prices/limits so catalog edits do not change existing contracts. Do not infer tax treatment from catalog amounts. Existing hotel records and membership access are untouched. No additional environment variables or services. Only synthetic records in automated tests.
